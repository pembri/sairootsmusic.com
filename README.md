# SAI Roots | Official Website

Selamat datang di repositori resmi **SAI Roots**. Ini adalah pusat data terstruktur dan aset digital untuk proyek musik solo SAI Roots yang dikelola secara eksklusif oleh **SAI Roots Music**.

## 👤 Tentang SAI Roots
SAI Roots adalah sebuah proyek musik beraliran **Reggae, Rap, dan Indie** asal Indonesia. Dikenal melalui karya-karya bermuatan pesan emosional dan kritik sosial yang kuat, menjadikannya salah satu ikon musik independen baru di Indonesia.

* **Project Founder & Producer:** Ahmad Supembri (Pembri)
* **Genre:** Reggae, Rap, Indie, Ska, Indonesian Hip Hop
* **Origin:** Indonesia

## 📁 Struktur Repositori
Berikut adalah detail struktur folder dan file utama dalam repositori ini:

### Folder (Directories)
* `admin_pages/`: Halaman manajemen internal.
* `article/`: Kumpulan artikel dan rilisan berita.
* `asset_gambar/`: Aset visual resmi (Foto profil & materi grafis SAI Roots).
* `discography/`: Dokumentasi diskografi resmi.
* `lyric/`: Library lirik lagu resmi.

### File Utama
* `index.html`: Halaman utama dengan optimasi JSON-LD Schema.
* `article.html` & `discography.html`: Template halaman konten.
* `lyric.html`: Halaman penampil lirik.
* `video_cover.html`: Halaman khusus konten video.
* `about.html`, `privacy.html`, `contact.html`: Halaman informasi dan legalitas.
* `404.html`: Halaman khusus untuk error navigasi.
