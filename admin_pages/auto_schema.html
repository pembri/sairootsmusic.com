Test Halaman Auto Schema

Buka Inspect Element -> tab Console untuk melihat status deteksi cerdas Schema.

Buka Inspect Element -> tab Elements -> <head> untuk memastikan Schema sudah berada di posisi paling atas.

Cara Test Fitur Darurat (Kill Switch):

  1. Buka Console browser Anda.
  2. Ketik hapusSchema() lalu tekan Enter.
  3. Lihat pesan *Error Merah* di console. Schema langsung hilang dari HTML.
  4. Refresh halaman (F5) berkali-kali. Schema akan tetap terblokir.
  5. Ketik aktifkanSchema() lalu tekan Enter untuk menyalakan ulang.
